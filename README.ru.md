# Twitter Hide Ads

**Модуль Xposed, который убирает продвигаемые посты и рекламу из X (Twitter).**

## Что делает

- Блокирует продвигаемые посты и рекламу до того, как X их отрисует: без пустых мест и без
  мелькания рекламы.
- Работает на главной, в просмотре поста и ответах, в поиске и во вкладке видео.
- После обновления X заново находит свои цели по структуре — ждать новой версии модуля не нужно.
- Если не уверен — ничего не трогает: обычные посты никогда не удаляются.

## Требования

| | |
|---|---|
| **Android** | 8.0 (API 26) или новее |
| **Приложение** | X (`com.twitter.android`) |
| **Фреймворк** | [Vector](https://github.com/JingMatrix/Vector) или другой фреймворк с libxposed API 101+, либо [LSPatch](https://github.com/JingMatrix/LSPatch) |
| **Root** | Нужен для Vector; самому модулю не нужен |

## Установка

1. Установите APK из [Releases](https://github.com/MrxSiN/TwitterHideAds/releases).
2. Включите **Twitter Hide Ads** в Vector (область действия уже задана — только X).
3. Один раз принудительно остановите X и откройте его снова.

**Без root:** встройте модуль в X с помощью [LSPatch](https://github.com/JingMatrix/LSPatch)
(патчите базовый APK вместе со всеми split-файлами).

## Как проверить, что работает

В журнале фреймворка найдите строки, начинающиеся с `TwitterHideAds:`.
`enforcement=ACTIVE_ADAPTIVE` означает, что модуль активен.

## Решение проблем

| Проблема | Что делать |
|---|---|
| Реклама всё ещё видна | Проверьте, что модуль включён и X был принудительно остановлен. |
| Перестал работать после обновления X | [Создайте issue](https://github.com/MrxSiN/TwitterHideAds/issues), указав версию X и строки журнала `TwitterHideAds:`. |

## Отказ от ответственности

Не связан с X Corp. или Twitter и не одобрен и не спонсируется ими. Для образовательного и личного
использования. Обновления X могут без предупреждения нарушить работу модуля.
