# Twitter Hide Ads v1.2.0

## Video Tab filtering and adaptive resolution

This release removes promoted videos from the full-screen Video Tab and starts resolving the Home timeline boundary by structure instead of by name.

### Added

- Video Tab filtering at the data layer: the module resolves the direct URT state-copy method whose first parameter and return type match and whose second parameter is a Kotlin immutable list, and removes only direct promoted timeline-post entries from mixed normal/promoted batches.
- A compatible immutable list is reconstructed and verified before it replaces the method argument.
- The resolved method is cached by X version and APK fingerprint.
- Adaptive structural resolution for the Home timeline pre-render boundary.
- A custom Twitter Hide Ads launcher icon, with legacy mdpi–xxxhdpi assets and adaptive, round and monochrome themed resources.

### Changed

- Fails open on ambiguous resolution, incompatible immutable-list copying or failed verification.
- The broad experimental video hook stack is removed. A read-only data-layer diagnostic identified `com.x.urt.o0$d.a(...)` as the mixed Video Tab batch boundary on X 12.10.1.
