# Twitter Hide Ads v1.1.0

## Stable support for X 12.8.0

This release adds an exact compatibility profile for X 12.8.0 alongside the 12.7.1 profile.

### Added

- Promoted-post suppression for X `12.8.0-release.0` through a dedicated compatibility profile:
  - `com.x.urt.items.post.w5$a`
  - `com.x.urt.items.post.d7.e(...)`
  - `com.x.urt.items.post.e.a(...)`
  - `com.x.urt.items.post.d7.a(...)`
- Version-aware selection between the validated X 12.7.1 and X 12.8.0 hook profiles.

### Changed

- Promoted-post model detection updated for the X 12.8.0 `w5$a` model.
- The temporary X 12.8.0 diagnostic scanner is replaced by exact, lightweight render hooks.
- Fallback hooks stay inactive unless the primary render boundary is unavailable.
- Release documentation and project metadata updated for the stable GitHub release.

### Version metadata

- Version name: `1.0.0` (as declared in the tagged build)
- Android version code: `18` (as declared in the tagged build)
- Git tag: `v1.1.0`
- APK filename: `app-release-unsigned-signed.apk`

### Updating

Install the APK over v1.0.0, then force-stop and reopen X once.
