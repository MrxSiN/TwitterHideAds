# Twitter Hide Ads v1.0.0

## First stable release

An Xposed module that removes promoted posts from X before they are drawn.

### Added

- Promoted-post suppression for X 12.7.1, applied at the Compose render boundary before the post is rendered, so no blank gap is left behind.
- Scope limited to the official X package, `com.twitter.android`.

### Version metadata

- Version name: `1.0.0`
- Android version code: `18`
- Git tag: `v1.0.0`
- APK filename: `app-release-unsigned-signed.apk`

### Installing

Install the APK, enable the module in LSPosed with X in its scope, then force-stop and reopen X once.
