# Twitter Hide Ads v1.3.0

## Home timeline suppression restored on X 12.22.0

X 12.22.0 restructured its render boundaries and the module had been failing open. This release finds them again by structure.

### Fixed

- Home timeline suppression works again on X 12.22.0-prod.01. The active boundary is `com.x.jetfuel.v2.element.attribute.h.h(...)`, declared outside the post package.
- Native libraries are packaged uncompressed. A deflated `libdexkit.so` cannot be loaded from inside the APK, so DexKit resolution had been failing with `UnsatisfiedLinkError` and falling back to a scan that found nothing.
- Resolved boundaries are deoptimized through LSPosed. ART inlines these composables into their callers, so hooks installed on them were never reached.

### Changed

- Render boundaries are identified by the post model they render rather than by the package they are declared in; the adaptive search previously covered only `com.x.urt.items.post`.
- Structural recognition moved into `RenderBoundaryShape`, matching parameters by role instead of by position. X 12.22.0 dropped the post-dependency parameter that the previous fixed 7-parameter layout required.
- Both the `Composer, $changed` and `Composer, $changed, $default` compiler shapes are accepted.
- Every boundary at or above the activation threshold is hooked instead of demanding a single winner; the defaulted and non-defaulted entry points of one composable score identically, so the ambiguity guard resolved to no hook at all.
- The bounded action-graph fallback is enabled for adaptive boundaries, since `com.x.models.TimelinePromotedMetadata` no longer exists as a class in X 12.22.0.
- Bounded per-boundary observation logging for diagnosing future X updates.
- The adaptive resolution cache format was bumped, so existing installs rescan.
