# Twitter Hide Ads v2.0.0

## Modern Xposed API

This release changes how the module is loaded and how it talks to the framework, without changing what it removes.

### Changed

- Uses the modern Xposed API (libxposed `102.0.0`), as implemented by [Vector](https://github.com/JingMatrix/Vector). Frameworks that only implement the legacy `de.robv.android.xposed` API 82 can no longer load the module.
- The module is described by `META-INF/xposed/` (`java_init.list`, `module.prop`, `scope.list`) instead of `assets/xposed_init` and the `xposedmodule`, `xposedminversion` and `xposedscope` manifest metadata. The entry point is `ModuleMain extends XposedModule`.
- Hooks are interceptor chains: a promoted post is suppressed by returning without calling `chain.proceed()`, and the Video Tab filter proceeds with a rebuilt argument array instead of mutating the original.
- Deoptimization goes through `XposedInterface.deoptimize`; `XposedHelpers` is replaced by plain reflection and the platform `PackageManager` APIs. Framework access is routed through `ModuleRuntime`.
- `minSdk` raised from 24 to 26, which the modern API requires; Java source and target level raised from 11 to 17.
- `AdaptiveHookResolver` split into candidate discovery (`BoundaryCandidateSource`), persistence (`AdaptiveBoundaryCache`) and ranking; the action-graph fallback moved into `PromotedActionScanner`.
- Rootless installation through LSPatch is documented: it embeds Vector into a patched APK and loads modern libxposed modules through the same runtime.

### Updating

Requires Android 8.0 or newer and a libxposed API 101+ framework (Vector). Install the v2.0.0 APK over v1.3.0, enable the module in Vector, then force-stop and reopen X once. Confirm the framework log reports `Application attach guard installed` followed by `Initialization complete`.
